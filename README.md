# STM32 电压采集节点 + Linux 终端监控器

一个从 MCU 裸机到 Linux 上位机的完整闭环项目：STM32 定时采样模拟电压，经自定义串口协议上报；Linux 端用 C 语言做串口解析与实时终端可视化。

---

## 一、项目做什么

- **STM32 侧（裸机）**：每 500ms 采样电位器电压，8 点滑动平均滤波，按自定义 6 字节帧经 USART1 上报；支持串口指令控制 LED、超阈值报警。
- **Linux 侧（上位机）**：C 语言打开串口、按协议解析帧，双线程（读串口 + 终端刷新）实时画 ASCII 电压条形图，带校验和与丢包统计。

## 二、硬件

| 器件 | 说明 |
|---|---|
| MCU | STM32F103C8T6 |
| 模拟源 | WH148 B10K 旋转电位器（模拟电芯/温度电压） |
| 通信 | CH340 USB 转串口 |

**接线：**
- 电位器两端 → 3.3V / GND，中间抽头 → PA0（ADC1_IN0）
- USART1：PA9(TX) → CH340 RX，PA10(RX) → CH340 TX，共地
- LED1 = PA1（500ms 心跳），LED2 = PA2（命令灯/超阈报警闪烁）

## 三、软件架构

```
电位器 → STM32 ADC → 滤波 → 组帧 → USART1(115200)
                                        │ CH340 / USB
                                        ▼
                            Linux: open+termios → poll → 状态机解帧
                                        │
                          pthread A: 读串口解析   pthread B: 每2s画条形图
```

- MCU：标准库 V3.5，TIM2 定时中断采样，中断内只做采样，换算/发送放主循环。
- 上位机：POSIX 接口（termios / poll / pthread），CentOS7 gcc 4.8.5 编译通过。

## 四、通信协议（定长 6 字节，大端）

| 字节 | 含义 |
|---|---|
| [0] | 帧头 `0xAA` |
| [1] | 通道 `0x01` |
| [2] | 电压×100 高字节 |
| [3] | 电压×100 低字节 |
| [4] | 状态位（bit0=1 表示超阈报警） |
| [5] | 校验和 = 前 5 字节累加的低 8 位 |

例：3.26V 正常 = `AA 01 01 46 00 F2`；超阈 3.18V = `AA 01 01 3E 01 EB`。

## 五、编译与运行

### STM32 侧
Keil MDK 打开工程，编译烧录即可。

### Linux 上位机（CentOS / Ubuntu）
```bash
make            # 编译全部
./monitor       # 运行最终成品（双线程条形图）
make clean      # 清理
```
运行前确保串口已直通进虚拟机并有权限：
```bash
ls /dev/ttyUSB*                      # 确认设备节点
sudo chmod 666 /dev/ttyUSB0          # 或把用户加入 dialout 组一劳永逸
./monitor /dev/ttyUSB0
```

三个版本递进：
- `serial_read`：原始字节打 HEX，验证链路
- `frame_parse`：状态机解帧，统计好/坏帧/失步
- `monitor`：双线程 + 条形图（最终成品）

## 六、技术要点（面试关注点）

- MCU：TIM 定时触发 ADC、滑动平均滤波、定长私有协议帧、中断与主循环分工、超阈报警用原始值快速判断
- 上位机：`termios` 配串口 raw 模式、`poll` 非阻塞读、状态机帧同步 + 校验和、`pthread` 双线程 + 互斥锁、ASCII 终端实时刷新
